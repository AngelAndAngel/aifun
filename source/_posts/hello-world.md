欢迎来到我的 Hexo 博客！

这是我的第一篇文章，使用 Markdown 编写，自动生成为漂亮的网页。

## 快速开始

1. 编辑 `source/_posts/` 目录下的 Markdown 文件
2. 运行 `npm run dev` 预览效果
3. 运行 `npm run build` 生成静态文件
4. 推送到 Git，Vercel 自动部署

## 特性

- 简洁优雅的界面
- Markdown 原生支持
- 代码高亮
- 响应式设计

开始写作吧！
